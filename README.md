# 🌱 EcoLife – Sustainable Living Website

EcoLife is a modern and responsive environmental awareness website designed to promote sustainable living, recycling, and nature conservation through an attractive user interface and inspiring eco-friendly content.

The website is built using HTML, CSS, Bootstrap, and JavaScript with a clean green-themed design focused on encouraging users to protect nature and adopt eco-conscious habits.

---

# 📌 Project Overview

EcoLife is an educational and awareness-based web project that highlights the importance of:

* Sustainable living
* Environmental protection
* Recycling
* Nature conservation
* Eco-friendly habits

The website includes:

* Responsive navigation
* Hero landing section
* Eco image galleries
* Nature awareness sections
* Feature cards
* Motivational sustainability messages
* Modern Bootstrap-based UI
